## app-ads.txt

https://izanapi.github.io/app-ads.txt に、同じ `pub-9744842808735051` の行が公開済みであることを作成時に確認しました。ルート側のファイルはこのリポジトリでは管理していません。

App Store ConnectのMarketing URLにはこのサポートサイトを設定できます。AdMob管理画面での認証完了・配信可否は別途確認してください。
